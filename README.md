# Akan Name Generator

##  Description

The Akan Name Generator is a simple web application that generates a traditional Akan name based on a user's date of birth and gender. Akan names originate from the Akan people of Ghana and are determined by the day of the week on which a person is born.

Users enter their birth date and select their gender, and the application calculates the day of the week and displays the corresponding Akan name.

---

##  Features

- Enter your date of birth
- Select your gender
- Calculates the day of the week you were born
- Displays the correct Akan name
- Input validation for empty or invalid fields
- Responsive and user-friendly interface

## 📋 How It Works

1. Enter your birth date.
2. Select your gender.
3. Click the **Generate Akan Name** button.
4. The application calculates the day of the week you were born.
5. Your Akan name is displayed on the screen.

##  Male Akan Names

| Day | Name |
|------|------|
| Sunday | Kwasi |
| Monday | Kwadwo |
| Tuesday | Kwabena |

| Thursday | Yaw |

## 🔍 Input Validation

The application checks that:

- A date has been entered.
- A gender has been selected.
- The date entered is valid.

If any required information is missing, the user receives an appropriate error message.
